# Bone & Child Medical Center Website

A professional medical website for a combined pediatric and orthopedic practice.

## 🏥 About the Website

This website is designed for a medical practice that combines:
- **Pediatrics** - Comprehensive healthcare for children and adolescents
- **Orthopedics** - Advanced treatment for bone, joint, and muscle conditions

## 📁 Website Structure

### Pages Created:
1. **Home Page** (`index.html`) - Hero section, specialties overview, why choose us
2. **About Page** (`about.html`) - Doctor profiles, practice story, mission & values
3. **Services Page** (`services.html`) - Detailed services for both specialties
4. **Contact Page** (`contact.html`) - Contact information, appointment booking form

### Files Included:
- `index.html` - Homepage with hero section and specialties
- `about.html` - About page with doctor profiles
- `services.html` - Services page with detailed offerings
- `contact.html` - Contact page with form and information
- `styles.css` - Complete responsive CSS styling
- `script.js` - Interactive JavaScript functionality
- `logo-placeholder.png` - Placeholder for logo (replace with actual logo)

## 🚀 Getting Started

1. **Open the website**: Simply open `index.html` in any web browser
2. **Customize content**: Update doctor names, contact information, and services
3. **Add logo**: Replace `logo-placeholder.png` with your actual logo
4. **Update contact info**: Modify phone numbers, addresses, and email addresses

The website is fully responsive and works on:
- Desktop computers
- Tablets

- All screen sizes

## 🛠 Customization Guide

### To Update Doctor Information:
1. Open `about.html`
2. Find the doctor card sections
3. Replace `[Brother's Name]` and `[Sister-in-law's Name]` with actual names
4. Update credentials, education, and specialties

### To Update Contact Information:
1. Open `contact.html`
2. Update phone numbers, address, and email
3. Modify office hours as needed

### To Add Your Logo:
1. Replace `logo-placeholder.png` with your actual logo file
2. Ensure the logo is approximately 40x40 pixels for best results

### To Update Services:
1. Open `services.html`
2. Modify the service descriptions and features
3. Add or remove services as needed
